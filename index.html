ما هو HTML؟

HTML هو اختصار لـ HyperText Markup Language

يعني: لغة ترميز النصوص الفائقة

⚠️ ملحوظة مهمة: HTML ليست لغة برمجة! هي لغة ترميز (Markup Language) تستخدم لبناء هيكل صفحات الويب.

🤔 لماذا نتعلم HTML؟

  • ✅ HTML هو أساس أي صفحة ويب على الإنترنت
  • ✅ بدون HTML لا يمكن بناء أي موقع
  • ✅ لغة سهلة التعلم ومناسبة للمبتدئين
  • ✅ مطلوبة في كل وظيفة Frontend Developer

البنية الأساسية لصفحة HTML

كل صفحة HTML لها بنية أساسية ثابتة. تعال ننظر إليها:

index.html
<!-- هذا هو الهيكل الأساسي لأي صفحة HTML -->
<!DOCTYPE html>
<html lang="ar">
<head>
    <meta charset="UTF-8">
    <title>صفحتي الأولى</title>
</head>
<body>
    <h1>مرحباً بك في أول صفحة ويب!</h1>
    <p>هذه أول فقرة أكتبها بنفسي</p>
</body>
</html>

📖 شرح الأجزاء:

الجزءالوظيفة
<!DOCTYPE html>يخبر المتصفح أن هذا ملف HTML5
<html>يحتوي على كل محتوى الصفحة
<head>معلومات عن الصفحة (لا تظهر للمستخدم)
<meta charset="UTF-8">لدعم اللغة العربية والحروف الخاصة
<title>عنوان الصفحة الذي يظهر في التاب
<body>المحتوى الذي يظهر للمستخدم

ما هي الـ Tags؟

Tag (وسم) هو أمر نخبر به المتصفح كيف يعرض المحتوى.

🔹 شكل الـ Tag:

  • Opening Tag (وسم فتح): <h1>
  • المحتوى: النص أو العناصر
  • Closing Tag (وسم إغلاق): </h1>

💡 مثال بسيط:

example.html
<h1>هذا عنوان رئيسي</h1>

أهم الـ Tags الأساسية

📝 1. العناوين (Headings)

headings.html
<h1>العنوان الأكبر</h1>
<h2>عنوان أصغر</h2>
<h3>عنوان أصغر</h3>
<h4>عنوان أصغر</h4>
<h5>عنوان أصغر</h5>
<h6>العنوان الأصغر</h6>
💡 نصيحة: استخدم <h1> مرة واحدة فقط في الصفحة (للعنوان الرئيسي).

📄 2. الفقرات (Paragraphs)

paragraphs.html
<p>هذه فقرة نصية عادية</p>
<p>وهذه فقرة أخرى</p>

➡️ 3. السطر الجديد والخط الأفقي

line-breaks.html
<br>   <!-- سطر جديد داخل الفقرة -->
<hr>   <!-- خط أفقي فاصل -->

💪 4. تنسيق النص

text-format.html
<strong>نص عريض (مهم)</strong>
<em>نص مائل (تأكيد)</em>
<u>نص تحته خط</u>

مثال عملي: صفحة تعريف شخصية

الآن سنبني معاً أول مشروع حقيقي! 🎉

<html lang="ar">

    <meta charset="UTF-8">
    <title>صفحتي الشخصية</title>
</head>

    <p>
        هدفي هو أن أصبح 
        <strong>Frontend Developer</strong>
         محترف!
    </p>
</body>
</html>

خطوات إنشاء ملف HTML

  1. افتح Notepad أو أي محرر نصوص (يفضل VS Code)
  2. اكتب الكود السابق بنفسك
  3. احفظ الملف باسم: index.html
  4. تأكد من اختيار Save as type: All Files
  5. اذهب إلى مكان الملف واضغط عليه مرتين
  6. ستفتح الصفحة في المتصفح! 🎉
⚠️ مهم جداً: احفظ الملف بامتداد .html وليس .txt

📝 الواجب — 5 مسائل عملية

المسألة 1: صفحة "عن المدرسة"

المطلوب: أنشئ صفحة HTML تحتوي على:

  • عنوان رئيسي: اسم مدرستك
  • عنوان فرعي: الشعار
  • فقرة تتحدث عن المدرسة
  • خط فاصل (<hr>)
  • فقرة أخرى عن أنشطة المدرسة

المسألة 2: صفحة "هوايتي المفضلة"

المطلوب: أنشئ صفحة تتحدث عن هوايتك المفضلة مستخدماً:

  • <h1> للعنوان الرئيسي
  • <h2> لعنوان فرعي
  • 3 فقرات على الأقل
  • استخدم <strong> و <em> في النصوص

المسألة 3: صفحة "أهدافي"

المطلوب: اكتب صفحة تتحدث عن أهدافك:

  • عنوان رئيسي: "أهدافي المستقبلية"
  • عنوان فرعي: "أهداف قصيرة المدى"
  • فقرتين عن أهدافك القريبة
  • عنوان فرعي: "أهداف بعيدة المدى"
  • فقرتين عن أحلامك المستقبلية

المسألة 4: تصحيح الأخطاء

المطلوب: ابحث عن الأخطاء وصححها في الكود التالي:

buggy.html
<!DOCTYPE html>
<html>
<head>
    <title>صفحتي
</head>
<body>
    <h1>مرحباً
    <p>هذه صفحتي</h1>
</body>

المسألة 5: مشروع حر

المطلوب: أنشئ صفحة HTML عن أي موضوع تحبه!
